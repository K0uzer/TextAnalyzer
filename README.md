# Text Analyzer

CLI-утилита на Go для базового анализа текста: считает строки, слова и символы, строит частотный словарь и выводит топ-N самых частых слов.

## Возможности

- 📄 Подсчёт количества строк
- 📝 Подсчёт количества слов
- 🔤 Подсчёт количества символов (рун, а не байт)
- 📊 Частотный словарь слов (с приведением к нижнему регистру)
- 🏆 Топ-N самых частых слов, отсортированный по убыванию частоты
- ✅ Покрытие тестами (табличные тесты)

## Требования

- Go **1.21+** (используется пакет `slices`)

## Установка

```bash
git clone https://github.com/<ваш-username>/textanalyzer.git
cd textanalyzer
go build -o textanalyzer .
```

Или запуск без сборки:

```bash
go run . -file article.txt
```

## Использование

```
textanalyzer -file <путь> [-top N]
```

### Флаги

| Флаг    | Тип    | По умолчанию | Описание                                |
|---------|--------|--------------|-----------------------------------------|
| `-file` | string | `""`         | Путь к файлу для анализа (обязательный) |
| `-top`  | int    | `10`         | Сколько слов вывести в топе             |

### Пример

```bash
go run . -file article.txt -top 5
```

### Пример вывода

```
Количество строк в тексте: 24
Количество слов в тексте: 156
Количество символов рун в тексте: 1093
Результат — слайс пар (слово, количество): [{в 11} {на 6} {аренды 5} {года 5} {жилья 4}]
```

## API

### `CountLines(text string) (int, error)`

Считает количество символов перевода строки (`\n`).

> ⚠️ Файл без завершающего `\n` вернёт `0`, даже если в нём одна строка. Функция считает именно переносы, а не «строки» в привычном смысле.

### `CountWords(text string) (int, error)`

Разбивает текст через `strings.Fields` (по пробелам, табам, переводам строк) и возвращает количество непустых слов. Лишние пробелы игнорируются.

### `CountChars(text string) (int, error)`

Считает количество **рун** (Unicode code points), а не байт. Поэтому `"привет"` — это 6, а не 12. Эмодзи с модификаторами (например, 👨‍👩‍👧) считаются как несколько рун.

### `WordFrequency(text string) (map[string]int, error)`

Возвращает словарь `слово → количество`. Все слова приводятся к нижнему регистру через `strings.ToLower`.

### `TopWords(freq map[string]int, n int) ([]WordCount, error)`

Сортирует словарь по убыванию частоты и возвращает первые `n` элементов. Если слов меньше `n` — возвращает все. Если `n <= 0` — возвращает `ErrQuantityNWords`.

### Сентинел-ошибки

```go
var ErrEmptyString    = errors.New("пустая строка")
var ErrQuantityNWords = errors.New("возвращаемое количество слов в слайсе равно нулю или меньше нуля")
```

Проверяются через `errors.Is` у вызывающего кода.

## Известные ограничения

- **Ввод читается целиком в память** через `os.ReadFile`. Для больших файлов стоит перейти на `bufio.Scanner`.
- **Ошибки выводятся в stdout**, а не в stderr.
- **`CountLines` считает `\n`**, а не «логические строки»: файл `"abc"` без перевода строки даёт `0`.
- **`CountChars` считает code points**, а не «визуальные символы». Составные эмодзи (флаги, семьи, тон кожи) будут посчитаны как несколько рун.
- **Нет поддержки stdin** — только файлы.
